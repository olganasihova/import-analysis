# Статистический анализ импорта Российской Федерации

Учебная курсовая работа по анализу импорта РФ за 2006–2024 годы.

## Что исследовано

- Динамика объёма импорта.
- Товарная структура и структурные сдвиги.
- Основные страны-поставщики.
- Связь импорта с ВВП и курсом доллара.
- Прогноз на 2025–2027 годы, представленный в курсовой.

## Файлы

- import_analysis.pdf — курсовая работа с таблицами, графиками и выводами.
- import_graphs.ipynb — восстановленный код построения графиков и расчёта линейной регрессии.

## Инструменты

Python, pandas, NumPy, matplotlib, Jupyter Notebook.

## Как открыть

PDF можно посмотреть на GitHub. Ноутбук можно загрузить в Google Colab и выполнить ячейки сверху вниз.

## О ноутбуке

Данные перенесены из таблиц курсовой и включены в код. Прогнозные значения взяты из курсовой: ноутбук показывает их на графике, но не рассчитывает заново. Полный набор расчётов курсовой в ноутбуке не воспроизводится.
